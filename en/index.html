What is this?

A complete Arabic translation of OMORI by Black with The Eternal Dream and Omori AR: all text and dialogue, every menu interface, the font itself rebuilt to support Arabic, and the game's written images redrawn in Arabic.

  • 18,308translated lines
  • 235translated images
  • 25technical plugins
  • 1.3current version

It installs as a mod on top of your existing copy of the game. It does not modify the game's core files.

What's translated?

Text & dialogue

Every line of dialogue from White Space to Black Space: 18,308 lines compared literally against the original English — zero formatting-token errors.

Menus

Title screen, options, save/load, shop, mail, quests, the encyclopedia, photo album, name entry, and the mod menu — all Arabic and mirrored right-to-left in the game's own style.

Battle UI

Battle log, party commands, skill bubbles, and the heart & juice bars — with a dedicated feminine form.

Images

235 in-game images redrawn in Arabic: signs, the game-over screen, minigames, posters, and the title-screen buttons.

The font

The OMORI GAME font itself was rebuilt to support Arabic letters — in-game text looks drawn by the game's own hand.

Correct grammar

Punctuation sits where it belongs, and the translation is hand-crafted, excellent, and proofread — because we care about quality.

Install guide

PC

  1. Download the patch file above.
  2. Install OneLoader: open your OMORI folder (right-click the game in Steam → Manage → Browse local files), then move the OneLoader folder into omori/www.
  3. Copy the Omori AR folder into www/mods/.
  4. Launch the game — Arabic UI and text appear immediately.

Android

  1. Download the APK above.
  2. Install it like any app (enable "unknown sources" if asked).
  3. Launch the game — everything is in Arabic from first boot.

FAQ

  • Is it free? Yes — like all fan translations. You still need an original copy of OMORI.
  • Does it change game files? No — it installs as a side-loading mod and can be removed by deleting one folder.
  • Are old save files compatible? Yes — but player names will show up in English because they're stored inside the save file. Any new game will display the name normally in arabic.
  • Does it support the feminine form? Yes — when Aubrey leads the party, the battle log and status messages are fully in the feminine form.
